# 欢迎使用 Highland Note

这是一个**本地优先**的 Markdown 笔记仓库：一个文件夹就是一个仓库，笔记就是普通的 `.md` 文件，
你随时可以用别的编辑器打开它们。

## 从这里开始

- 左侧文件树里右键可以新建、重命名、删除
- 按 `Ctrl` + `N` 新建笔记，`Ctrl` + `P` 按名字跳转
- 按 `Ctrl` + `E` 在「编辑 / 分栏 / 预览」之间切换
- `Ctrl` + `S` 保存（其实停手几百毫秒就会自动保存）

## 双向链接

用双方括号把笔记连起来，例如 [[卡片盒笔记法]]，也可以给链接起个别名：[[每日笔记|今天的笔记]]。
预览或实时预览里按住 `Ctrl` 点击链接就能跳过去；目标不存在时会问你要不要新建。

## 标签

正文里写 #笔记方法 或 #工具/编辑器 就是标签，点一下能在右侧搜出所有相关段落。

## 表格

| 功能 | 快捷键 |
| --- | --- |
| 快速跳转 | Ctrl + P |
| 新建笔记 | Ctrl + N |
| 切换视图 | Ctrl + E |
| 开关侧边栏 | Ctrl + B |
| 保存 | Ctrl + S |

> 提示：光标停在某一行时，那一行会显示原始的 Markdown 标记，方便你直接改语法。
